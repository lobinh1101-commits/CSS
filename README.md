# Bài Thực Hành: Tạo Giao Diện Giản Lược Trang Chủ Facebook

## Mục tiêu
- Thiết kế thanh tiêu đề cố định (**Fixed Header**) ở trên cùng.
- Tạo các thanh điều hướng hai bên (**Left & Right Sidebar**).
- Dựng khu vực bảng tin chính (**Feed Content**) căn giữa linh hoạt.

## Cấu trúc thư mục
- `index.html`: Cấu trúc HTML5 mô phỏng Facebook.
- `styles.css`: CSS layout sử dụng Flexbox, Fixed Positioning và Responsive design.
- `README.md`: Hướng dẫn nộp bài.

## Hướng dẫn nộp bài lên GitHub
1. Giải nén file `jwbd-facebook-ui.zip`.
2. Tạo một repository mới trên [GitHub](https://github.com/) với tên `jwbd-facebook-ui`.
3. Đẩy 3 file `index.html`, `styles.css`, `README.md` lên repository.
4. Sao chép URL repository và dán vào phần nộp bài.
