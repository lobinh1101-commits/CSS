# Bài Thực Hành HTML5/CSS: Tạo Layout Với Thẻ Semantic HTML5

## Mục tiêu
- Thành thạo việc tạo bố cục (layout) trang web sử dụng các thẻ Semantic trong HTML5 (`header`, `nav`, `article`, `aside`, `footer`).
- Định dạng bố cục bằng CSS Flexbox linh hoạt và có khả năng tương thích Responsive trên các thiết bị di động.

## Cấu trúc thư mục
- `index.html`: Cấu trúc trang web theo các thẻ HTML5 Semantic.
- `styles.css`: CSS định dạng màu sắc, bố cục Flexbox và khoảng cách.
- `README.md`: Tài liệu hướng dẫn bài tập.

## Hướng dẫn nộp bài lên GitHub
1. Tải về tệp `jwbd-html5-layout.zip` và giải nén.
2. Tạo một repository mới trên [GitHub](https://github.com/) với tên `jwbd-html5-layout`.
3. Đẩy 3 tệp `index.html`, `styles.css`, `README.md` lên repository.
4. Sao chép liên kết GitHub và dán vào phần nộp bài.
