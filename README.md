# Bài Thực Hành HTML/CSS: Tạo Menu Ngang (Horizontal Dropdown Menu)

## Mục tiêu
- Luyện tập sử dụng CSS để xây dựng thanh điều hướng dạng ngang (Horizontal Navigation Bar).
- Tạo hiệu ứng menu thả xuống (dropdown) khi đưa con trỏ chuột (`:hover`) qua các mục chính.
- Sử dụng thuộc tính `float: left`, `position: relative`, `position: absolute`, `visibility: hidden/visible` để định vị vị trí menu con.

## Cấu trúc thư mục
- `index.html`: Chứa cấu trúc thẻ danh sách lồng nhau (`ul` > `li` > `ul`).
- `styles.css`: Chứa định dạng giao diện menu ngang và hiệu ứng hiển thị menu con.
- `README.md`: Hướng dẫn chạy và nộp bài.

## Hướng dẫn chạy dự án
1. Mở tệp `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox).
2. Rê chuột vào các mục **Sem 1** hoặc **Sem 2** để kiểm tra hiệu ứng thả xuống dạng ngang của menu con.

## Hướng dẫn nộp bài lên GitHub
1. Tải về và giải nén tệp `jwbd-make-navbar.zip`.
2. Tạo một repository mới trên [GitHub](https://github.com/) với tên `jwbd-make-navbar`.
3. Tải các file `index.html`, `styles.css`, `README.md` lên repository.
4. Sao chép liên kết (URL) của repository và dán vào phần nộp bài.
